How Immigration Metrics sources, validates, and explains immigration data.

How data is handled

We prefer primary government sources and record each dataset's source URL, retrieval time, source date when explicitly reported, checksum, validation status, and quality warnings. A source's data-as-of date is not treated as its publication date.

The Department of Labor FLAG processing-time page is parsed from a reviewed official HTML structure. The currently published dataset is a single verified snapshot. Queue indicators describe an aggregate cohort; they are not an individual's case status, queue position, or decision date.

The Department of State Visa Bulletin index returned HTTP 403 during verification. We do not infer its file format, scrape around access controls, or publish sample values as official data. Fictional interaction fixtures are marked DEMO / SAMPLE wherever shown.

We do not calculate personal predictions from one aggregate average. Validation failures should preserve the last verified snapshot and expose the source's availability status rather than silently presenting stale data as current.
