About Immigration Metrics

About this independent immigration information project.

Independent immigration data, with limitations made visible

Immigration Metrics is an independent informational project that organizes source-linked U.S. employment-based immigration indicators. It is not affiliated with the U.S. government, a law firm, or an immigration representative.

The project is static-first and does not require user accounts or submit personal dates to a server. We distinguish verified official observations from unavailable sources and fictional interface samples.
